## 4. Alpha 标签、背景和依赖

唯一主窗口15m；辅助1m、5m、30m、60m，全数披露，不能重选主窗口。
P0为信号时刻最后已见SOL成交价，Ph为截止时刻最后已见成交价：

- LONG forward return = `Ph/P0 - 1`；SHORT = `P0/Ph - 1`，bps乘10000。
- 每SOL方向价格距离仍为 LONG `Ph-P0`、SHORT `P0-Ph` USDT。
- **SHORT Alpha 的倒数口径不等于 USDT-M线性合约 PnL/notional**，交易盈亏只按
  已声明合约现金流计算，不套倒数公式制造利润。
- MFE/MAE保存方向价格距离、对应方向收益及最早可见极值时间、time_to_MFE/MAE。
  包含起点作为0距离，MAE报非负不利幅度；同价极值选最早，不能选更漂亮的时间。
- 保存原结构失效首次可见时点及失效前MFE（不含失效事件）；之后反弹另列，
  不回填为原计划可实现收益。MFE不是成交利润，forward return也不是退出成交。

标签路径为 `(t,t+h]` 的已可见事件；截止>=正式期末为CENSORED。每窗口独立报告
全部／完整／缺失／截尾／匹配数量。端点年龄>=15s或路径可见事件间隔>=15s为
覆盖不足；不跨缺口插值制造高低点，不用短窗口替换缺失长窗口，不能填0。

背景固定每 UTC15分钟格点，对四策略原支持的方向使用同一价格和标签规则。
不依据未来收益选背景；即使该点有信号也不剔除。原样均值差与分层差分别报告。
主指标是15m方向收益的**候选加权、同层背景差**（bps）；不是策略利润。

预定义层为：方向 × UTC小时 × 事前波动档 × 当时SOL趋势档 × BTC环境档。
波动用过去300秒 `(最高-最低)/当前价*10000`，档 `[0,10),[10,25),[25,50),
[50,100),[100,+inf)` bps；SOL15m与BTC3m方向均用 `[-inf,−.1%),[−.1%,.1%),
[.1%,+inf)`。BTC额外记录 `<=−.8%` 风险状态，不按未来涨跌分层。
缺同层背景标UNMATCHED，不临时并层；按UTC日／周、波动、原方向同时描述稳定性。

两套固定权重：ALL、DEDUPED（每策略/side/UTC15分钟格点最早，平局按事件序号
与signal_id）。每套分别重算背景匹配、统计与自身区间；不得挪用ALL的区间。
去重后仍可能有60m窗口重叠，不称独立交易。若ALL正而DEDUPED不正或其证据不清晰，
标 `EDGE DEPENDS ON CLUSTERED SIGNAL WEIGHTING`，不声明稳定优势。

输出mean、median、p25/p75、MFE/MAE及时序、背景mean、差异、共同支持比例。
不确定性为配对UTC日块重采样：61日、10000次、种子808072；信号与背景按同一
起点日成块抽取，保留块内重叠，每次重新匹配和加权。日块不能消除所有跨日依赖。
描述95%区间；A评审涉及四策略各ALL/Dedup主Alpha及Baseline EV共12个固定指标，
采用Bonferroni双侧99.583333%百分位区间（尾部各.002083333）。辅助窗口不参与
结果择优，少量日块与稀疏分层的局限必须报告。

| Signals/Trades | ALL与DEDUP信号、已开路径、已完整结束、未平／截尾／不可表达／重叠跳过分别计数；部分退出不是新交易 |
| Win rate | 完整交易正PnL数/n，零盈亏另列 |
| Average win/loss、Payoff | 正PnL均值、负PnL绝对值均值及前者/后者；分母0为null及原因，不画无穷优势 |
| PF | 正PnL总和/负PnL绝对值总和；分母0同上 |
| EV | 完整交易PnL均值；概率加权正负均值必须与之相等；bps逐笔用自身原始入场名义量，不用SHORT Alpha倒数公式 |
| Gross/Net及成本 | 参考现金流、各腿fee、spread、slippage、rounding、funding逐项守恒到净PnL |
| Max/average drawdown | 每事件mark-to-market权益相对运行峰值的差；最大差及按实际时间加权平均差；包括未平浮动与费用，不只算已平 |
| Consecutive losses | 按退出时序完整交易负PnL连续数，非负断开 |
| Holding | 首次入场至最终退出，均值/中位数；未平持有另报不混入完整样本 |
| Trades/day | 完整交易数/全部正式61UTC日，另报活跃日口径 |
| Monthly return | 不复利单位路径每月净权益变化/固定500USDT展示基数；不是实盘账户收益率 |
| Return/MaxDD | 全期净权益变化/MaxDD；MaxDD为0或资料缺失则null |
| Sharpe | UTC日净权益变化/500的日序列，均值/样本标准差×sqrt(365)，含零交易日；仅辅助，不作为唯一评级 |

每UTC周、波动档、原方向输出n、EV、PF、净PnL、MDD。周MDD含该周实际在途
mark-to-market，跨周交易计数归最终退出周但不能把前周浮亏移除。
按日/周完整交易正PnL贡献，同时披露净PnL：bestday、bestweek、top5trades占
全体正PnL之比；净总PnL>0时另报对净PnL贡献，不能只选好看的分母。
预定义 `EDGE_CONCENTRATED`：bestday>30%，或bestweek>50%，或top5>40%的正PnL。
