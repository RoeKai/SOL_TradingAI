## 3. 研究顺序、假说与有限实验集合

先合成正确性测试 → 八月仅工程检查 → 数据资格确认 → 正式期 Alpha →
锁定 Alpha 输出 → 同一正式期交易层 → 固定评级。Alpha 不显著时仍披露该策略
交易层结果，不隐藏失败策略；不得改规则后重复验证同一未见样本。

每策略假说 H_A：原信号之后固定窗口的方向变化相对同方向背景有正增量。
每策略假说 H_T：原退出规则在声明 Baseline cost 下的单位仓位净期望为正且稳定。
两者分别检验；H_A 成立不推出 H_T 成立。最初三策略的 SHORT 为
`NOT_IMPLEMENTED_BY_ORIGINAL_STRATEGY`，不能强加镜像增加实验数量。

每条策略唯一 Alpha 主指标是 **15 分钟方向调整 forward return 的候选加权分层
信号减背景差（bps）**。辅助固定 1、5、30、60 分钟，全部披露，不改称最好的
一档为主窗口。交易层唯一主指标为 Baseline cost 下每完整单位仓位净盈亏均值；
其他指标为稳定性／风险约束和辅助描述。

实验集合仅四策略 × 五窗口 × 原样／固定去重；成本仅 Gross、Fee-only、Baseline
三个口径。没有参数网格、方向择优、额外币种、最佳日期或最优阈值搜索。
SOLUSDT 为信号标的，BTC／ETH只按原实现过滤／准备状态，不增加新信号策略。

## 4. Alpha 标签、背景、去重与依赖

按原评分间隔 0.5s 和原新行情时间检查调用原策略，保存其真实产生时刻／最后
有效原始观察时间，不能改成 later 15 秒精确重获采样。所有输入可见时间必须
不晚于决策时刻，后续标签读取器与候选生成器分离，结果不能被执行层导入。

设 d 为 LONG +1、SHORT −1，P0 为信号时刻最后已可见成交价，Ph 为截止时刻
最后已可见成交价：`return_usdt_per_sol=d*(Ph-P0)`；`return_bps=10000*d*(Ph-P0)/P0`。
五窗口均保存截止、实际端点时刻、MFE／MAE、原结构首次观察失效及失效前 MFE。
极值不是退出成交价；先失效后反弹不能当原计划盈利，观察失效不是实盘止损。

端点原事件年龄必须小于 15s，路径成交间隔≥15s记覆盖不足。盘口／指标是否可用
另列，不用一个缺失字段抹掉其他事实。期限到达／超过正式期末为 `CENSORED`，
不从七月31日或八月补未来标签、不改短窗口。每策略／方向／窗口公布原始、
完整、截尾、缺失、未匹配分母。无法计算用 null，不用 0 伪装失败或安全。

背景从正式 UTC 起点每 15 分钟固定取点，对原实现支持的方向计算同样标签；
不按之后涨跌选点，不排除恰好有信号的点。两类样本共用价格可见性和覆盖规则。
分层固定为方向 × UTC 日 × UTC 小时 × 当时可见 300 秒波动档，波动为
`10000*(past_high-past_low)/current_price`，档位 `[0,10),[10,25),[25,50),[50,100),[100,+∞)` bps。
缺同层背景记未匹配，不借未来或相邻层；披露未调整与分层差、日／月／波动／方向稳定性。

去重版本固定为每策略每方向每 UTC 60 分钟格点中最早信号，平局按 signal_id，
不按收益挑选。它仅为权重敏感性，不替换主样本；不同格点的标签仍可能重叠，
不称为独立交易。背景保持同一固定网格，去重版本单独重算自身不确定性。

不确定性用配对 UTC 起点日块重采样，整个块包含全部重叠信号与对应背景，
91 日、10,000 次，种子 `808072`。不能用37,141等旧标签数冒充新策略独立样本。
报告95%描述区间；评级同时考察四个主 Alpha 与四个主交易均值，共8个预登记
统计量，使用 Bonferroni 99.375% 双侧百分位区间（下尾0.003125，上尾0.996875），
不得拿描述95%区间替代评级区间。有限天数、跨日依赖、分层稀疏和多重比较局限必须说明。
辅助窗口／方向不用于新增确证或选择“只做空”。

## 5. 交易层：单位仓位历史路径，不是正式账户／审批

本轮交易层是**每策略独立、固定 1 SOL、不复利的历史单位仓位研究**，
不是运行原账户、放开原硬风控或新增完整模拟盘。这样可以在成本口径之间
保持同样数量，不让不同仓位把成本影响掩盖。历史规则不允许1 SOL或分腿最小量时
明确拒绝／不可表示，不自动上调数量。原账户风控、账本、恢复代码不修改。

按全部原信号的时间顺序研究；同策略同时只跟踪一个单位仓位，已有仓位期间
新信号仅计 Alpha 和 `OVERLAP_SKIPPED`，不加仓、不开第二仓。研究层不假定这些
建议获得了原 Admission 或账户风控批准；完整模拟盘将来仍须通过全部现有风险约束。
该区别必须出现在最终每张交易统计表中，不能把单位仓位成交路径数叫真实账户成交数。

原信号给出的方向、参考入场、原止损、1R／2R 50/50目标冻结，不按实际成交价
重新拉远目标。初始止损按原执行精度方向规范化，原值与规范化值同时记录，
不改写原信号。用信号时刻已可见的盘口／最后成交生成同事件的立即成交假设，
保持原简单 PaperBroker 语义；不是实际排队、部分成交或流动性充分性的证明。

后续逐事件处理；保守可退出边 LONG=min(last,bid)、SHORT=max(last,ask)，
止损优先于TP。同事件跨两档时逐档按原始数量分配，最后一档退出全部余量。
跳空按当时可成交报价加不利成本，不保证止损价成交。没有有效报价不造平仓。
不加入原实现没有的保本、Runner、尾仓跟踪或60分钟强平；60分钟只是 Alpha 标签窗口。
期末未平仓标截尾，已实现与浮动盈亏分开，不能用有利最终价强制平仓以完成统计。

### 5.1 三个固定、配对的成本口径

先确定 Baseline 的事件顺序、入场／退出时间和数量，然后对**同一组单位仓位
与同一退出时点**做配对成本归因，不各自搜索会多盈利的成交路径：

- **Gross**：各腿同一时点最后已可见成交参考价；不扣手续费、价差、滑点、资金费。
  它是该固定交易组的乐观参考现金流，不声称参考价能实际成交。
- **Fee-only**：同一 Gross 参考价与数量，每次入场／部分退出按原声明每侧
  `0.0005` 费率计费；不计价差、滑点、资金费。费率未经账户核验。
- **Baseline cost**：实际历史盘口边，按原 `PaperBroker.fill` 向不利方向
  加每腿10bps滑点；按模型成交价计每侧0.0005费用；使用持仓时真实到期的历史
  资金费×相同剩余数量×对应mark，保留正负收付。历史资金费仅到时进入账务，
  不反向筛选信号；无资料记 `COST_DATA_MISSING`，不能补0。精度按冻结历史规则
  或明确声明规则，后者不能冒充真实历史能力。

盘口已经进入Baseline价格，不重复扣一笔价差。三表必须配对 signal_id、数量、
分腿与时间；另列Gross到Fee-only到Baseline的变化，以及未完成／规则拒绝数。
不得把Baseline资金费后来结算事实当作事前可知预测；不改原前置资金费／执行预算。
本轮不新增滑点敏感性档位，不降低10bps，不增加有利成交概率或虚构盘口。

### 5.2 固定统计口径

每策略及其支持方向，每个成本口径都必须输出：

| 指标 | 固定定义 |
| --- | --- |
| 信号数 | 原引擎实际建议数；另列原始、去重、缺失、未匹配数 |
| 交易数 | 已开路径数、完整平仓数、部分／期末未平数分列；分批退出不是多笔完整交易 |
| 胜率 | 完整交易pnl>0的数量／完整交易数；零盈亏单列 |
| 平均盈亏 | 完整交易pnl均值，USDT/1SOL；平均盈利和平均亏损绝对值也分列 |
| 盈亏比 | 平均正盈利／平均负亏损绝对值；不与原计划理论RR混称 |
| Profit Factor | 正pnl总和／负pnl绝对值总和；分母0报未定义和计数，不渲染无限优势 |
| 期望 | 胜率×平均盈利−亏损率×平均亏损，必须等于每完整交易均值；不是未来保证 |
| 回撤 | 统一按事件mark-to-market累积单位仓位收益曲线的峰谷差；USDT及以固定500USDT为展示基数的比例；不是已过风险的账户回撤 |
| 样本依赖 | 信号重叠数、按日块区间、活跃日及每月样本；不报告iid显著性 |

曲线包含未平仓浮动与已实现费用／资金费；最后未平仓不能从回撤中消失。
数据缺口使曲线部分未知时明确标记，不能以已知点低估真实回撤并取得A。
同时按 UTC 月、事前波动档和原方向分组，披露n及全部三成本口径。
不会因某方向差就临时关闭它；前三策略无SHORT是原实现限制，不是本月方向筛选。
